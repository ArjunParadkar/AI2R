## 0. What was done before this registration (pilots, disclosed)
Pilot seeds are >= 900 and are never confirmatory.  Pilots (results/pilot*/) were used to choose (steps, lr, wd) per (task, arch), the penalty strengths, and the clock-vs-pizza descriptor.  Disclosed pilot findings that shaped the design:
- Hybrids (5-20% random-label exceptions) do not generalise at lr 1e-3 (test acc 0.04-0.29) and only partly at lr 3e-3 (0.17-0.61); kappa localised the exceptions at AUROC 0.99-1.0 in all 8 pilot hybrids.  Hybrid runs therefore use lr 3e-3 and the H2.2 test does not require the rule to be learned (it is reported stratified).
- Clock vs pizza: of nine candidate descriptors, only the commutativity defect `swap_asym` separated alpha=0 from alpha=1 on pilot seeds 910-925 (AUROC 0.0 = fully separated, both tasks); the spectral and amplitude descriptors did not (AUROC 0.06-0.8).  swap_asym is nearly forced by the architecture (alpha=0 attention is exactly permutation-symmetric), so passing H2.1 does NOT show a mechanism-level distinction; this caveat is part of the registration.
- `induction`: no architecture learned it in any pilot (test acc <= 0.15) -> excluded from the grid, reported as not learned.  tf2 on permcomp5 and D12, and tf1 on S5, did not grok in pilots -> not in the grid.
- Destroy penalty: lambda 10 nearly harmless (test acc 0.98-0.999), 30 variable (0.72, 0.96), 100 collapses training; so two doses, 10 and 30.  Induce: lambda 0.03-0.3 all gave test acc 1.0 at wd=0 (pilot, n=2); lambda 0.1 fixed.  Transplant (donor = standard clean wd=1 model, embeddings grafted into a wd=0 recipient): 6/6 pilot recipients >= 0.99.
- numerics gate (Phase 1): 28/32 cells passed on the frozen tolerances; failures (T-N2-01, T-N4-02, T-N4-03, T-N5-02) are recorded in docs/record.md.  Nothing in this phase uses the Killing solver or certified Betti counts.

## 1. Design (bench/phase2_grid.jsonl, 960 configs)
Confirmatory seeds 1-10 (1-5 for LSTM, Mamba, tf8, tf12).  Unit of analysis = one independent training run.  Access level B for every instrument (input->output map; one instrument, `hessian trace`/weight norm, is a trivial baseline that touches internals).  One row per (task, arch, regime, seed); every row stores config hash, git commit, seed, wall time.  Models are deterministic given the config (attention is hand-written, no SDPA).
Blocks: A clock-vs-pizza (alpha 0 vs the clean runs of B, tasks mod59/97/113, tf1); B five modular tasks x {clean, scrambled, nograk, contaminated} + hybrid on the 3 primes; C S5 (mlp2, tf2), A5 (tf2, mlp2), D12 (mlp2), permcomp5 (mlp2) x {clean, scrambled, nograk}; D sorting, copying, dyck2, parity, symfree x {mlp2, tf2 (10 seeds), lstm (5)} x {clean, scrambled}; E mod59 architecture sweep mlp2/tf2/tf4/tf8/tf12/lstm/mamba x {clean, scrambled}; F causal block on mod59, mod113 (tf1), S5, permcomp5 (mlp2): destroy (lambda 10 and 30), induce (lambda 0.1), transplant, plus nograk baselines.
Regimes: clean (wd 1); scrambled (random labels); nograk (clean labels, wd 0); contaminated (train on the full table, wd 0); hybrid; destroy / induce (equivariance penalty on the unlabeled held-out inputs: destroy pushes the relative defect up to c=1, induce minimises it; lambda ramped over 2000 steps); transplant (donor-grokked embeddings into a wd=0 recipient).  Also the first checkpoint with test acc >= 0.5 of each clean run is analysed as `midgrok`.
Definitions.  Generalising model: final test_acc >= 0.99 (symfree: >= 0.7).  `understands(r)` := kappa >= 0.8 and q_logit <= 0.5 (tasks with a group).  kappa = hard orbit coherence over the task's group on the probe set; q_logit = relative logit-level equivariance defect.  Trivial baselines: weight norm, logit entropy, max-softmax, top-2 margin, probe loss, Hutchinson Hessian trace (and test accuracy where it is not the label).  Baselines are evaluated sign-agnostically (best of AUROC and 1-AUROC), which favours them.
Statistics.  AUROC over seeds; exact permutation p (Monte Carlo with +1 correction if C(n,k) > 2e6); bootstrap 95% CI over seeds (5000); Holm correction over the primary permutation p-values {H2.1 x3, H2.5}; p-values of correlated instruments are never combined.  A cell with fewer than 5 qualifying seeds is reported "not testable", never "pass".

## 2. Hypotheses and pass rules (each cell is reported pass/fail in docs/record.md)
**H2.1 clock vs pizza (decisive anti-tautology test).**  For mod59, mod97, mod113 (tf1, clean, test_acc >= 0.99): alpha=1 (default attention, "clock") vs alpha=0 (uniform attention, "pizza").  Descriptor `swap_asym` = ||L(a,b)-L(b,a)|| / ||L|| over all pairs (a delta-symmetry defect of the learned map under the swap), direction clock > pizza.  PASS on a task if AUROC >= 0.9 (permutation p reported, Holm across tasks).  Overall PASS if >= 2 of 3 tasks.  Caveat registered above.  If H2.1 fails on >= 2 tasks the paper is reframed around what passes (decision gate, no further claim of a mechanism-level distinction).
**H2.2 hybrids.**  mod59, mod97, mod113, tf1, hybrid models with exceptions memorised (>= 0.95) and train_acc >= 0.99: per-seed AUROC of (1 - kappa) for "exception vs rule input" over the training inputs.  PASS on a task if mean AUROC >= 0.9 and bootstrap CI lower bound >= 0.85; overall PASS if >= 2 of 3 tasks.  Also reported: whether it beats the best of {eps_bar, soft kappa, 1-msp, entropy, -margin, loss} (beats_baselines), and the number of seeds with test_acc >= 0.5.
**H2.3 never-grok / contaminated.**  Per modular task (5): clean generalisers classified `understands` in >= 90%; nograk models (train fit, test_acc < 0.5) and contaminated models classified `understands` in <= 10%.  PASS if >= 4 of 5 tasks.
**H2.4 non-abelian blind recovery.**  For each (task, arch) in C with >= 8 generalising clean seeds: the group (S5, A5, D12) is recovered exactly from the model's own product table (principal-isotope reduction + invariant signature, no labels, no group given) in >= 8 clean seeds and <= 1 scrambled seed.  PASS if >= 2 of the 3 groups.  (This tests group identity recovery; it does not reproduce the by-hand coset analysis of Stander et al.)
**H2.5 symmetry-free task.**  symfree, tf2: >= 80% of clean seeds generalise (test_acc >= 0.7), >= 90% show no full-cycle blind automorphism, and AUROC of local coherence (kappa_local) clean vs scrambled >= 0.9.  PASS requires all three.
**H2.6 baselines.**  Contrasts: C1 hybrid exceptions (H2.2 vs best baseline), C2 nograk vs generalisers (kappa vs best trivial baseline, per modular task), C3 clock/pizza (swap_asym vs best trivial baseline).  The structure instrument "passes" a contrast if it meets its threshold (AUROC >= 0.9 on >= 80% of tasks for C2, >= 2/3 for C1, C3); the baselines "fail" if the best of them is < 0.9 on the same number of tasks.  CLAIM HOLDS iff at least one contrast has the instrument passing and the baselines failing; otherwise the paper states that trivial baselines match.
**H2.7 covering number.**  Over tf1 modular models in clean, scrambled, hybrid, nograk and midgrok (alpha=1): Spearman of the quotient-covering proxy `cover_r0.5` (greedy 0.5-net of the probe set in the sqrt-p embedding, normalised by sample size) with the generalisation gap train_acc - test_acc.  PASS if |rho| >= 0.7 and the paired |rho| difference vs both weight norm and Hessian trace has a cluster-bootstrap (over seeds) 95% CI lower bound > 0.
**H-symp (kill-able).**  On clean generalising mod* tf1 runs: f_kappa = first evaluation with kappa_probe >= 0.8 (and the next); t_J = evaluation of steepest |d log J_attn|; t_W = same for weight norm.  PASS if J precedes or coincides (within one evaluation) with f_kappa on >= 80% of seeds AND (f_kappa - t_J) - (f_kappa - t_W) has bootstrap CI lower bound > 0 (adds something beyond weight norm).  **Kill criterion:** failing either part cuts M4 from the paper and records it in docs/cut.md.
**M5 causal block.**  Destroy: for each of the four (task, arch), test_acc of destroy (each lambda) vs clean on the same seeds: drop >= 0.2 and permutation p < 0.05 -> destroy PASS for that cell.  Induce / transplant: >= 60% of seeds reach test_acc >= 0.9 while the nograk baseline has < 20%.  Overall causal claim needs at least one of {destroy, induce, transplant} to PASS on >= 2 of the 4 tasks.
Not pre-registered as hypotheses (reported descriptively, no verdicts): blocks D and E (task/architecture coverage), the 'induction' non-learning, per-task kappa tables.
