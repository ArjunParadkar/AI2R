Every panel is generated from a results file by a script under analysis/ and re-rendered here in colour and in Raleway (analysis/color/, figures/color/). Tags give the verdict of the pre-registered cell the figure belongs to: PASS and FAIL are by the letter, PARTIAL is a mixed block, and DESCRIPTIVE means no criterion was registered. Colour here is for reading; the figures in the reports use hatching and line style so that identity survives greyscale printing.

The scorecards seven grids, one per run

Rows are the seven problems; each column is a run. The grids accumulate: the seven-run grid is the whole record.

Run 1 the ten-hour specification · 19–20 Sept

One object: the activation manifold at each layer with the metric pulled back from the output, g = JᵀJ.

Run 2 the Morse-theoretic upgrade · 20 Sept

Depth profiles, kernel displacement, Morse–Smale separatrices, functional alignment, vineyards. Shape can be re-encoded; function cannot.

Run 3 the symmetry group · 20 Sept

What a network knows is a symmetry group. Instruments verified on planted truth first; the group is found, post-hoc, as a full 113-cycle among statistically accepted permutations.

Run 4 the tower of quotients · 20 Sept

True memorisers first. The group registered in advance and found on unseen seeds; the definition of understanding scored and failed by the letter.

Run 5 registration · 21 Sept

Nothing proposed. Run-4 numbers written down as thresholds and scored on eleven models trained afterwards.

Run 6 orbit-closure · 21–22 Sept

Can the group also say what the network does not know and where it will fail? Orbit coherence κ and equivariance defect ε against the softmax family and Golan's designer transformations.

Run 7 the extractor, and the end · 22 Sept

A learned symmetry is one the trained network keeps and the untrained network does not. Subtract the architecture; what remains is what the network learned to ignore.
